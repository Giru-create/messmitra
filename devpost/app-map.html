MessMitra Architecture Map

Commit 6f2de8b

MessMitra is a client-side Next.js web application empowering hostel students to anonymously report food complaints in English and Hinglish, and mess committees to cluster issues, triage critical hygiene risks, and measure before-and-after resolution impact.

Data & Control Flow Architecture

Key Code Tour & Reference Stops

src/lib/analyzer.ts • analyzeFeedbackOffline()

The core heuristic NLP engine. Inspects raw strings for hygiene triggers (e.g., insect, keeda, kankad) or temperature/shortage complaints in English and Hinglish. Assigns urgency, category, and normalized issue keys in <5ms without external API calls.

src/components/StudentFeedbackForm.tsx • handleSubmit()

Handles the mobile-friendly input form (meal selection chips, 1-5 star rating, and Hinglish textarea). Passes user input directly to the analyzer and pushes the validated entry into state.

src/components/ImpactTracker.tsx

The closed-loop impact engine. Calculates complaint frequency for each recurring issue before vs. after the committee's implementation timestamp, proving whether an intervention actually solved the student complaint.

src/lib/storage.ts • getStoredFeedbacks() / saveFeedbacks()

Encapsulates browser localStorage interactions with safe SSR mounting checks to prevent Next.js hydration mismatches.

To Change This App, Start Here

  • Add new Hinglish food keywords: Open src/lib/analyzer.ts and add tokens to insectPattern, coldPattern, or shortagePattern.
  • Modify the demo records: Open src/lib/demoData.ts to customize the pre-loaded 14 hostel entries.
  • Adjust UI color palette: Check tailwind.config.ts and component classes in src/components/Header.tsx.
A Practice to Reuse: Offline Heuristic Prototyping.
Instead of depending on an external cloud LLM for early demos, starting with a rule-based offline NLP classifier gave MessMitra instant response times, zero billing overhead, and 100% demo reliability. An optional cloud LLM hook can always be layered on top later.
